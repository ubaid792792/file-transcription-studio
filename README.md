# File Transcription Studio

In-browser audio and video file transcription using Whisper via Transformers.js. Files never leave your device.

**Live app:** https://ubaid792792.github.io/file-transcription-studio/

## How to use

Open `index.html` in a modern browser (or use the live link), pick an audio or video file, and start transcription. The model downloads once and runs locally.

## Privacy

No API keys or personal data are stored in this repository.
